# Brain Tumor MRI Classification

## Overview

A deep learning project for classifying brain MRI images
into different brain tumor categories.

## Objectives

- Perform exploratory data analysis on MRI images
- Preprocess MRI images
- Develop a deep learning classification model
- Evaluate model performance
- Develop a simple prediction application
